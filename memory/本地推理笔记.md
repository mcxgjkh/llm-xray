# 本地推理笔记

本机通过 LM Studio 提供 deepseek-r1-distill-llama-8b。推理接口优先使用 /v1/responses 以获得 top-logprobs，失败时按 400/404/405 降级到 /v1/chat/completions，最后才使用原生 /api/v1/chat。连接错误不重试，避免在模型加载期间反复请求造成卡顿。

采样重算在前端完成：重复惩罚按最近若干 Token 的出现次数调整 logit，再依次应用温度、Top-K、Top-P 与 Softmax，不重新请求模型。

如果只想演示界面，使用 demo 模式；它不加载任何模型，逐 Token 产生可信的 top-k 分布、熵与时间戳。
